- library-incident.js: 조사 대사 / 능력 대사 / 제갈 미나 상태 대사 / 브리핑 / 엔딩

- 게임 규칙
- 수치
- 상태 전이
- CSS / 레이아웃
- 아이콘

수정 기준
1. 각 인물이 게임 규칙을 설명하는 '오퍼레이터'처럼 같은 문장 구조를 쓰는 현상을 줄임.
2. 화영: 하오체·소인·몸으로 먼저 확인하는 4차원 행동성을 강화.
3. 강운심: 제보/캡처/업로드/SNS 언어와 빠른 말투를 강화.
4. 에피: 저장·소유·카오 중심의 짧고 소유적인 말투를 강화.
5. 이난: 차분한 의료 어휘와 위험한 치료법을 무심하게 꺼내는 성격을 강화.
6. 김우주: 시스템 어휘는 유지하되 회피성·피로감·미나와의 악연을 추가.
7. 마근아: 규정 문장과 구체 시각/기록 확인을 강화. 설명형 메타 대사는 축소.
8. 변아리: 추상적 '정화'보다 소독·박리·오염선·가브리엘의 구체 행동을 강화.
9. 조상민: '효율'을 직접 설명하기보다 움직이기 싫어하는 이유가 말에서 드러나게 함.
10. 제갈 미나: 일반적인 AI 안내문 톤만 반복하지 않고, 억지 정상 판정·책임회피·신체 이상을 시스템 오류로 우기는 인간성을 섞음.

특히 피한 문장 경향
- 캐릭터가 자신의 게임 효과를 그대로 설명하는 문장
- 누구에게 붙여도 성립하는 '정확한 상황 판단 + 계획 발표'형 대사
- 감정이나 주제를 멋있게 요약하는 엔딩 문장
- 지나치게 매끈한 전문직/오퍼레이터 말투의 평준화

문법 검사
- 4개 JS 파일 모두 node --check 통과
