# 튜토리얼 구현 메모

## 경계

- **[CANON]** 캐릭터 이름, 소속, 능력 원리와 패널티 요약은 `lore/characters/`에 근거한다.
- **[GAME]** 교실 괴이, 학생 3명, 단서, 전투 효과와 모든 수치는 게임 전용이다.
- **[GAME]** HP 0이나 위험 상태는 원작의 영구 사망이 아니다. 학생 위험은 사건 실패 후 재시작을 뜻한다.

## 현재 [GAME] 값

- 파티 4명, 전열/후열, 캐릭터당 1행동, AP 없음, 교대 없음.
- 속도 값으로 턴 순서를 정렬한다. 캐릭터 HP와 속도는 `src/data/characters.js`에서 조정한다.
- 학생 상태는 `정상 → 혼란 → 반복 고착 → 위험` 플래그이며, 한 명이라도 위험이면 실패한다.
- 학생 전원 정상화와 `안전 이탈` 행동이 승리 조건이다. 적 HP 0은 필수 조건이 아니다.
- 탐색 단서 2개 이상이면 `반복 원인 끊기`를 해금한다. 이 조건과 압력 감소량은 튜토리얼 임시값이다.

## 수정 지점

- 캐릭터 데이터: `src/data/characters.js`
- 사건 데이터와 탐색 목록: `src/data/tutorial-endless-classroom.js`
- 상태 전이와 행동 규칙: `src/engine.js`
- 텍스트 UI: `src/index.html`, `src/app.js`, `src/styles.css`

## 사건 03 구현

- **[GAME]** 사건 03 「존재하지 않는 도서관 정상 운영 안내」를 `game/events/library-reality-audit.md` 기준으로 구현했다.
- 데이터 → 엔진 → UI 경계를 `src/data/library-incident.js` → `src/library-engine.js` → `src/library-app.js`로 유지한다.
- 초기 조사는 5곳 중 3곳이며 한 지점에서 한 접근법만 선택한다. 초기 조사만으로 사실을 잠글 수 없다.
- 증거 조합은 정답 대신 플레이어의 판정 선택지를 연다. 오판은 `misverified`로 남으며 행동을 써 재판정할 수 있다.
- 개별 증거 진행률 대신 사실 단위 재조사를 사용하고, 첫 고정부터 `audit → collapse` 전환과 고정 순서 결과를 적용한다.
- 관계 상호작용과 캐릭터 능력은 관측·보호·예측·오염 억제를 제공하지만 정답을 자동 판정하지 않는다.
- 사건 03의 기존 `styles.css` 시각 규칙은 이번 시스템 보강에서 변경하지 않았다.
- 사건 03 완료 보상으로 제갈 미나가 이후 사건용 명단에 해금된다. 사건 03 안에서는 계속 현장 협조자 NPC다.
