# 존재하지 않는 도서관 정상 운영 안내 — [GAME] 사건 03

> 상태: **[GAME IMPLEMENTED]**
>
> 도서관 사고, 세 사실, 증거·판정·고정 순서·현상 수치는 모두 `[GAME]`이다.

## [CANON] 활용 근거

- 제갈 미나는 도서관 사서이며 `[할루시네이션]`으로 자신이 우긴 정보를 현실에 덮어쓴다.
- 처리량이 과도하거나 인과율을 넘으면 블루스크린처럼 기절한다.
- 김우주의 해킹, 마근아의 규칙 집행은 미나의 방식과 충돌한다.
- 강운심과 마근아는 규칙과 정보 공개 방식이 정면으로 부딪힌다.

위 사실 외의 사건 발생 경위와 규칙은 게임 전용이다.

## [GAME] 목표와 사실

- F1 실제 인원: 진실 `3명`, 현재 현실의 주장 `5명`
- F2 안전 동선: 진실 `북측 비상구`, 현재 현실의 주장 `서측 서가`
- F3 최초 오염: 진실 `미나의 최초 오발`, 현재 현실의 주장 `검색 DB 오류`

`truth`는 불변이다. 플레이어가 관측을 해석해 `playerClaim`을 선택하고, 진실과 일치하면 `verified`, 다르면 `misverified`가 된다. 세 사실을 모두 `locked`로 만들면 성공한다.

## [GAME] 조사와 판정

- 다섯 지점 중 서로 다른 세 곳을 조사하며, 한 지점에서는 한 접근법만 선택한다.
- 증거 문장은 출입 서명, 표시 인원, 하중, 반사음, 생성 시각처럼 관측된 값만 제공한다.
- `verify` 조합은 정답을 자동 확정하지 않고 판정 선택지를 개방한다.
- 엔진의 충돌 관측 API는 동시에 성립하는 모순을 UI에 제공한다.
- F3의 `witness-time + shared-result`는 `원인 추적` 행동을 열며, 그 행동도 정답 대신 판정 선택지를 제공한다.

오판은 즉시 실패가 아니다. `misverified`는 안정도와 해당 사실의 오염 효과를 악화시키지만, 새 증거·재조사·복원 뒤 행동 한 번으로 다시 판정할 수 있다.

## [GAME] 사실 단위 재조사

개별 증거 진행률을 반복해서 채우는 대신 `F1/F2/F3 재조사`를 사용한다. 한 번의 재조사는 해당 사실에서 부족한 핵심 증거 하나를 확보하며, 사실당 성공한 재조사는 최대 두 번이다.

- F1: `counter-memory + official-record`
- F2: `physical-route + evacuation-rule`
- F3: `first-statement + mina-load`

F1의 가짜 이용자는 재조사 행동을 가로챌 수 있고, F2의 가짜 동선은 안정도 비용을 만들며, F3의 정정 반동은 미나 부하를 높인다.

## [GAME] 고정 순서와 진행 단계

해결 구간은 `audit → collapse`로 나뉜다. 첫 사실을 고정하는 순간 `collapse`로 전환하고 후반 패턴 순환을 시작한다.

- F1 선고정: `phantomTargets` 제거, 미고정 F2의 `routeRisk +1`
- F2 선고정: `routeRisk` 제거, 미고정 F3의 정정 반동과 미나 부하 증가
- F3 선고정: 후반 패턴 강도 완화, 미나 부하 즉시 `+2`

`lockOrder`는 결과 기록에 남는다. 성공 조건은 같지만 첫 고정 직후의 안정도, 미나 부하, 활성 오염 효과와 후반 압력이 달라진다.

## [GAME] 현상과 관계

전반은 재작성·출처 소실 중심, 후반은 확신 편향 비중이 높은 별도 고정 순환을 사용한다. 확신 편향은 `misverified`를 가장 먼저 노리고, 출처 소실은 판정 자료만 한 라운드 비활성화한다.

- 우주 ↔ 미나: 시스템 증거 보호, 다음 오류 표적 예측
- 마근아 ↔ 미나: 공식 증거에 재작성 1회 거부 부여
- 운심 ↔ 마근아: 비정규 조합으로 판정 선택지 개방, 안정도 -1

관계 효과와 캐릭터 능력은 정답을 대신 판정하지 않는다.
