# Game Design

게임 구현을 위해 추가하는 시스템과 설정을 보관합니다.

예:
- 게임용 능력치
- 시스템 수치
- 이벤트 조건
- 게임 전용 대사

여기의 내용은 원작 캐논과 구분합니다.

## 프로토타입 표현 범위

프로토타입은 텍스트 기반 게임으로 만든다. 사용자 승인 전에는 새 이미지 에셋을 생성하거나
외부에서 가져오지 않는다. 캐릭터는 이름, 텍스트 설명, 능력 설명, 관계 정보, 텍스트 기반 UI로
표현한다. HTML/CSS/JS의 기본 UI·단순 도형과 프로젝트에 이미 명시적으로 포함된 에셋만 사용할 수 있다.
그래픽이 필요할 경우에는 텍스트 기반 placeholder를 사용한다.
